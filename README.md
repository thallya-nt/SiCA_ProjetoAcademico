## PROJETO ACADÊMICO - SiCA [SISTEMA DE COMPARTILHAMENTO DE ARQUIVOS] - W SOCKETS TCP

O SiCA é um sistema desenvolvido para permitir a transferência segura e direta de arquivos entre um cliente e um servidor. A comunicação é realizada por meio do protocolo de transporte TCP, garantindo que os dados sejam entregues na ordem correta e sem perdas.

> *Este projeto foi construído respeitando todos os requisitos e especificações solicitados pela disciplina.*
---

1. **O QUE É ESTE PROJETO 📂** - Como o próprio nome sugere, o projeto em questão aborda um sistema cliente-servidor de compartilhamento de arquivos
 via *sockets TCP*.

2. **O QUE É PRECISO SABER ANTES DE TESTAR O CÓDIGO 🔍** - Certifique-se de que a pasta `arquivos_cliente` e `arquivos_servidor`
não estão vazias.

3. **FUNCIONALIDADES DO CÓDIGO ⚙️**
   * Envio de arquivos `enviarArquivos()`;
   * Recebimento de arquivos `baixarArquivos()`;
   * Listagem de arquivos `listarArquivos()`.
